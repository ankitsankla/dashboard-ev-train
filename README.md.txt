# EV Market Performance Dashboard

## Project Overview
The **EV Market Performance** project analyzes the electric vehicle (EV) market using Tableau. It turns vehicle data into interactive visualizations that help users explore market trends, manufacturer performance, and the distribution of electric vehicles.

## Objectives
- Understand the overall EV market using the available dataset.
- Compare EV manufacturers and their vehicle counts.
- Explore vehicle characteristics and market distribution.
- Build interactive Tableau sheets and combine them into a dashboard.
- Present data in a clear format to support data-driven insights.

## Dataset
The project uses an EV dataset containing vehicle-level records. Depending on the fields available in the source file, the analysis may include:
- Vehicle ID
- Manufacturer
- Vehicle make or model
- Vehicle type or category
- Other available vehicle attributes

3. **Market Distribution** — shows how vehicles are distributed across available categories.
4. **Vehicle Comparison** — compares available vehicle attributes.

## Key Questions
The dashboard is designed to help answer questions such as:
- Which manufacturers have the highest number of vehicles in the dataset?
- How is the dataset distributed across manufacturers and vehicle categories?
- Which patterns stand out when comparing the available vehicle attributes?
- What does the dataset reveal about the EV market represented in the source data?

## How to Use the Dashboard
1. Open the Tableau workbook (`.twb` or `.twbx`).
2. Open the **EV Market Performance Dashboard**.
3. Use available filters and interactive chart selections to explore the data.
4. Hover over marks to view tooltips and detailed values.
5. Select different manufacturers or categories to compare results.

## How to Open the Project
1. Install Tableau Desktop or use a compatible Tableau environment.
2. Download or clone this project folder.
3. Open the Tableau workbook file.
4. If Tableau asks for the data source, reconnect it to the supplied dataset.
5. Open the dashboard and interact with the visualizations.
